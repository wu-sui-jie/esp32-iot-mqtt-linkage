# 8 号板 · 光照度传感器模块（light_sensor）

## 这个模块是干什么的

测环境光照度，每 2 秒上报一次。**纯传感器板**，只管上报，不接收任何命令。

它上报的数据会驱动两件事：

- 5 号板的光照联动——太暗就自动开照明
- 7 号板的语音——低于阈值时播报「光线过暗，请注意」

---

## 硬件与接线

| 项目 | 引脚 | 说明 |
|---|---|---|
| BH1750 SDA | GPIO21 | I2C 数据线 |
| BH1750 SCL | GPIO22 | I2C 时钟线 |
| VCC | 3.3V | |
| GND | GND | |

BH1750 的 I2C 地址是 `0x23`。

代码里还留了一条降级路径：如果上电时检测不到 BH1750，就改用光敏电阻（ADC，GPIO34）。不过本组的板子上装的就是 BH1750，这条路径实际不会被走到。

## 单独调试与验证

这块板可以**脱离其他七块板单独验证**。需要的东西：本板 + USB 线 + MQTTX。

### 第 1 步：上电自检

烧录后打开串口监视器（波特率 115200），正常应该依次出现：

```
[proto] WiFi 已连接，IP = 192.168.x.x
[proto] MQTT 已连接
[proto] 已订阅 202609_PP2/1/cmd
[light] 检测到 BH1750 数字光照度传感器（I2C，地址 0x23）
```

**卡住时按这个顺序排查**：

| 串口停在这里 | 说明 |
|---|---|
| `连接 WiFi` 后面一直点点点 | 热点名字或密码不对，改本模块 `my_config.h` 里的 `WIFI_SSID` / `WIFI_PASSWORD` |
| `MQTT 连接中...` 反复刷 | 服务器地址不对，或者网络没放行 1883 端口 |
| 没有最后那一行模块日志 | 外设接线问题，见下面「常见问题」 |

### 第 2 步：验证清单

| # | 检查项 | 怎么做 | 通过标准 |
|---|---|---|---|
| 1 | 板子活着 | 看串口 | 打印出上面那段启动日志 |
| 2 | 网络通 | 看串口 | 出现 `[proto] MQTT 已连接` 和订阅成功 |
| 3 | 能收命令 | 不需要发命令（纯传感器） | — |
| 4 | 能上报 | 订阅区收到本板的 dat | 什么都不做，2 秒内应收到一条带 illuminance 的 dat |
| 5 | 联动（可选） | 不适用（本板是传感器，只报数） | — |

这一轮走完，说明这块板本身没有问题了。具体的报文内容和预期现象在下面各节里。
重点确认：数值会不会随遮光/照光变化。

## 报文格式

### 上行数据（dat）

```json
{"ver":"1.0","type":"dat","seq":76,"src":"8","dst":0,"body":{"device":"light_sensor","samples":[{"key":"illuminance","value":125.5}]}}
```

| key | 含义 | 单位 | 范围 |
|---|---|---|---|
| `illuminance` | 光照度 | lx | 0.0 ~ 65535.0 |

保留 **1 位小数**（协议表 15）。

### 上线

```json
{"ver":"1.0","type":"sys","seq":1,"src":"8","dst":0,"body":{"device":"sys","event":"online","uptime":12}}
```

## 怎么测

上电后串口每 2 秒打印：

```
[light] 光照度 125.5 lx
```

上电时还会打印识别结果，可以确认传感器通信正常：

```
[light] 检测到 BH1750 数字光照度传感器（I2C，地址 0x23）
```

**想造"过暗"的条件**：用手捂住传感器，或者用书本挡住。数值应该迅速掉到 50 lx 以下，这时：

- 5 号板的 RGB 会亮起暖白光
- 7 号板会播报「光线过暗，请注意」

**想造"变亮"的条件**：用手机手电筒照传感器。升到 120 lx 以上，5 号板的灯就会熄灭。

两个阈值都写在 **5 号板**的 `my_config.h` 里（`LIGHT_DARK_LUX` 和 `LIGHT_BRIGHT_LUX`），本板不参与判断，只负责报数。

### 读不到数据

BH1750 读取失败时本板会**跳过本周期、不上报**，串口打印：

```
[light] 读取失败（I2C 无应答），本周期不上报
```

这是刻意的：如果读到一半失败就退回光敏电阻，而板上根本没接光敏电阻，那一路读的是悬空引脚的噪声，上报出去就是一条假数据。宁可少一条，也不要发一条错的。

## 常见问题

| 现象 | 先查什么 |
|---|---|
| 串口打印"未检测到 BH1750" | SDA/SCL 接反或没接；传感器供电；I2C 地址是否为 0x23 |
| 数值一直是 0 或不动 | 传感器被测物体贴住了；或者通信失败（看串口有没有读取失败的提示） |
| 数值和手机测的差很多 | 正常，BH1750 测的是它自己那个位置的照度，和手机传感器位置不同 |
| 5 号板的灯不跟着亮 | 5 号板是否在线；它的 `SUB_EXTRA_REPORT` 是否为 1；光照有没有真的降到 50 lx 以下 |

## 可调参数

都在 `esp32_light_ir/my_config.h`：

```c
#define BH1750_ADDR 0x23        // I2C 从机地址
#define LIGHT_SDA 21            // I2C 数据线
#define LIGHT_SCL 22            // I2C 时钟线
#define LIGHT_REPORT_PERIOD_MS 2000UL  // 上报周期
```
