  物联网多平台联动系统 · Web 控制台 功能与设计说明

============================================================

一、程序概述
------------------------------------------------------------
Web 控制台是本物联网系统的上位机监控平台，采用纯前端实现
（HTML + CSS + JavaScript），通过 WebSocket 连接远程 MQTT
服务器（yunyismart.tech:9001），实现对 8 块 ESP32 开发板的
远程监控、命令下发和联动调试。

整个页面为单页应用，无需任何后端框架，打开 index.html 即可
运行。外部依赖仅有一个：通过 CDN 引入 mqtt.js 库
（https://unpkg.com/mqtt/dist/mqtt.min.js）。


二、功能模块
------------------------------------------------------------

1. MQTT 连接与状态管理
   - 页面加载后自动通过 WebSocket 协议连接 MQTT 服务器
   - 自动订阅 report 主题（接收传感器数据/事件/回执）和
     online 主题（接收设备上下线通知）
   - 顶部状态栏实时显示连接状态（已连接/已断开），并展示
     最近一条消息的摘要
   - 支持断线自动重连（间隔 2 秒）

2. 设备在线状态面板
   - 以网格形式展示 1~8 号板的在线/离线状态
   - 每个设备节点带有圆形指示灯：在线为绿色发光，离线为灰色
   - 通过解析 online 主题中的 sys 类型报文自动更新

3. 八块设备控制/监测卡片
   每张卡片对应一块 ESP32 开发板，按功能分为三类：

   【执行器】
   - 1号板 · 舵机：滑块选择 0~180° 角度，点击"设定"发送命令；
     界面带有模拟舵机臂的圆形动画，实时跟随角度旋转。
   - 2号板 · 风扇：开/关按钮控制继电器；界面有三叶风扇旋转
     动画，开启时持续旋转，关闭时停止。
   - 7号板 · 语音播报：输入文本（最长 100 字节），点击"播报"
     发送 TTS 命令到 7 号板进行语音合成播放。

   【传感器】
   - 3号板 · 红外对射：显示光束通畅/遮挡状态和遮挡计数；
     状态以色块变化提示（绿色通畅、红色遮挡）。
   - 4号板 · 温湿度：显示温度（℃）和湿度（%）数值，并配有
     渐变色进度条直观展示当前环境状态。
   - 6号板 · 火焰：显示火焰检测状态（正常/检测到火焰）和
     模拟强度值，火焰检测时图标闪烁动画警示。
   - 8号板 · 光照度：显示光照强度（lx）值及进度条，并根据
     亮度自动划分等级（黑暗/较暗/光照适宜/强光），配以
     对应图标。

   【综合】
   - 5号板 · RGB/蜂鸣器：三个滑块分别控制 R/G/B 值（0~255），
     实时预览混合颜色（圆形色块带发光效果）；蜂鸣器独立
     开/关控制。

4. 报文解析与数据分流
   收到 MQTT 消息后，按协议规范进行两层解析：
   - 第一层：信封字段（ver / type / src / dst / seq）
   - 第二层：根据 type 字段分流处理
     · dat（周期数据）→ 更新温湿度、光照度、火焰强度、遮挡计数
     · evt（事件）    → 更新红外对射遮挡/恢复、火焰检测/清除、
                        联动状态（风扇自动启停、RGB 场景切换）
     · ack（回执）    → 确认命令执行结果，更新界面反馈
     · sys（系统）    → 处理设备上线/离线

5. 联动调试面板
   这是本 Web 端的特色功能，用于在不依赖真实传感器触发的
   情况下，手动模拟传感器事件，触发板端本地联动逻辑：

   - 火焰 → RGB + 蜂鸣器（6号 → 5号）
     点击"模拟火焰检测"向 report 主题发布 src=6 的 flame
     detected 事件报文，5 号板旁听后触发多彩循环灯光 +
     蜂鸣器间歇报警；点击"模拟火焰消失"解除报警。

   - 红外对射 → 舵机（3号 → 1号）
     点击"模拟光束遮挡"发布 src=3 的 ir_beam blocked 事件，
     1 号板旁听后自动将舵机转到 0°；恢复后舵机回到 90°。

   - 温湿度 → 风扇（4号 → 2号）
     点击"模拟高温高湿"发布 src=4 的 sht30 dat 报文
     （温度 35.2℃ / 湿度 85%），2 号板判断超标后自动开启
     风扇；模拟正常环境后风扇延时关闭。

   每次模拟操作同时更新 Web 界面上对应设备的状态显示，
   并在消息日志中记录模拟报文内容。

6. 消息日志
   - 等宽字体终端风格的消息滚动区域
   - 按类型着色：发送（蓝色）、接收（绿色）、系统（黄色）
   - 每条日志带时间戳和方向标识（→ 发送 / ← 接收 / ★ 系统）
   - 自动限制最多 200 条，防止内存溢出
   - 提供"清空"按钮


三、设计思路
------------------------------------------------------------

1. 纯前端轻量架构
   整个 Web 端仅由 HTML + CSS + JS 三个文件组成，不依赖
   Vue/React 等框架，也不依赖后端服务。用户只需用浏览器
   打开 index.html 即可使用。MQTT 通信通过 mqtt.js 库的
   WebSocket 协议实现，无需额外代理。

2. 协议驱动的报文设计
   所有通信严格遵循《MQTT 通信协议规范_第1组》V2.0，采用
   「信封 + 载荷」双层 JSON 格式：
   - 信封层：ver（版本号）、type（报文类型）、seq（序列号）、
     src（源）、dst（目标）
   - 载荷层：device（设备标识）、action/event（动作/事件）、
     param（参数）
   这种设计使报文具有明确的寻址能力和可扩展性，Web 端与
   板端只需遵循同一协议即可互通。

3. 卡片式 UI 布局
   每个设备独立一张毛玻璃风格卡片，按功能类型标注不同颜色
   的徽章（执行器蓝色/传感器绿色/综合橙色）。卡片采用
   Flexbox 网格自适应排列，在不同屏幕宽度下自动换行。

4. 深色主题 + 毛玻璃视觉风格
   采用深蓝紫渐变背景（#0f0c29 → #24243e），卡片使用
   backdrop-filter: blur(10px) 实现毛玻璃效果，配合半透明
   边框和悬停高亮动效，营造现代化的科技感界面。

5. 可视化设备状态反馈
   不同于简单的数字显示，Web 端为每个设备设计了直观的
   可视化组件：
   - 舵机：CSS 旋转动画模拟真实舵机臂角度
   - 风扇：CSS 关键帧动画模拟扇叶旋转/停止
   - 火焰：缩放闪烁动画模拟火焰警示
   - RGB：实时混色预览 + 发光阴影效果
   - 温湿度/光照/火焰强度：渐变色进度条

6. 联动调试的"模拟报文注入"思路
   联动调试面板的核心思路是：Web 端扮演"虚拟传感器"，
   向 report 主题发布符合协议规范的模拟报文。由于各板的
   联动逻辑是旁听 report 主题实现的，因此这些模拟报文能
   真实触发板端的联动响应，实现了：
   - 无需物理操作传感器即可测试联动逻辑
   - Web 界面同步显示数据变化，便于观察
   - 报文格式与真实传感器完全一致，保证协议兼容性


四、文件结构
------------------------------------------------------------
  index.html   — 页面结构，定义所有 UI 元素和联动面板
  style.css    — 深色主题样式，含动画定义和响应式布局
  script.js    — MQTT 连接、报文解析、命令发送、UI 更新、
                 联动模拟等全部业务逻辑


五、MQTT 主题与通信方向
------------------------------------------------------------
  202609_PP2/1/cmd     Web → 板端（命令下发）
  202609_PP2/1/report  板端 → Web（数据/事件/回执）
                       Web → report（联动模拟报文注入）
  202609_PP2/1/online  板端 → Web（设备上下线通知）


六、技术要点
------------------------------------------------------------
  - 通信协议：MQTT over WebSocket（端口 9001）
  - QoS 等级：订阅 QoS 1，发布命令 QoS 1，模拟报文 QoS 0
  - 客户端 ID：web_ + 8位随机十六进制串，避免冲突
  - 发送序号：txSeq 从 1 开始自增，超过 65535 自动回绕
  - 日志限制：消息日志最多保留 200 条，超出自动移除最早的


七、总结
------------------------------------------------------------
Web 控制台以「协议一致、轻量部署、可视直观、调试便捷」为
设计理念，在纯前端条件下实现了对 8 块 ESP32 开发板的完整
远程监控与控制，并创新性地提供了联动调试面板，极大方便了
系统开发过程中的联调测试。
