# RFID读卡功能修改说明

## 修改概述
将原来的VL53L0X激光测距功能改为RFID读卡功能。

## 硬件连接
- RFID读卡模块连接到ESP32的串口2（Serial2）
- 波特率：115200

## 通信协议
### 读卡命令
每1秒发送一次读卡命令：
```
AA BB 00 00 00 02 20 01 23
```

### 响应格式
1. **无卡响应**（8字节）：
   ```
   AA BB CC CC 00 02 20 01 23
   ```

2. **有卡响应**（17字节）：
   - 前4字节：`AA BB CC CC`（响应头）
   - 第13-16字节：卡号信息（4字节）
   - 其他字节：协议相关数据

## 代码修改内容

### 1. sensors.h
- 移除了VL53L0X相关的头文件和函数声明
- 添加了RFID相关的宏定义和函数声明
- 定义了读卡命令和响应格式

### 2. sensors.cpp
- 完全重写了传感器功能
- 实现了`RFID_init()`函数：初始化串口2
- 实现了`readRFIDCard()`函数：
  - 发送读卡命令
  - 解析响应数据
  - 提取卡号信息
  - 返回卡号字符串

### 3. Sensor_IIC_RFID-HF.ino
- 修改了变量定义：从距离相关改为卡号相关
- 更新了初始化函数调用
- 修改了主功能函数`mainFunction()`
- 更新了显示界面函数`ShowRFIDDashboard()`
- 添加了JSON数据格式定义`JSON_DATA_RFID`

### 4. platformio.ini
- 移除了DFRobot_VL53L0X库依赖

## 功能特点
1. **自动读卡**：每1秒自动发送读卡命令
2. **卡号提取**：自动解析响应并提取4字节卡号
3. **MQTT上报**：将卡号信息通过MQTT发送到服务器
4. **TFT显示**：在TFT屏幕上显示当前读卡状态和卡号
5. **状态检测**：检测卡号变化，只在有变化时上报

## 数据格式
MQTT发送的JSON数据格式：
```json
{
  "commType": "Wifi",
  "sensorType": "RFID", 
  "data": {
    "card_id": "12345678"
  }
}
```

## 使用说明
1. 确保RFID模块正确连接到ESP32的串口2
2. 配置WiFi和MQTT服务器信息
3. 设置传感器类型为"01"
4. 上电后系统会自动开始读卡
5. 当检测到RFID卡时，卡号会显示在TFT屏幕上并通过MQTT发送

## 注意事项
- 确保RFID模块的波特率设置为115200
- 卡号以16进制字符串形式返回（大写）
- 无卡时返回空字符串
- 系统会自动处理通信超时和错误响应
