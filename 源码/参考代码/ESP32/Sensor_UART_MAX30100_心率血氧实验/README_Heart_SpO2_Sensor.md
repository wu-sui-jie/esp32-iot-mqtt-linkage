# 心率血氧传感器功能说明

## 功能概述
本项目已从RFID读卡器功能修改为心率血氧传感器功能，通过串口2接收心率血氧数据并显示在TFT屏幕上。

## 硬件连接
- 心率血氧传感器连接到ESP32的串口2（UART2）
- 串口2引脚：
  - TX2: GPIO17
  - RX2: GPIO16

## 数据格式
串口2接收的数据格式为：
```
Heart rate:86.15bpm / SpO2:96%
```

## 功能特点
1. **串口2初始化**：波特率115200
2. **数据解析**：自动解析心率（bpm）和血氧饱和度（%）
3. **实时显示**：在TFT屏幕上显示心率和血氧数据
4. **MQTT上传**：将数据通过WiFi上传到MQTT服务器
5. **数据更新**：每秒接收一次数据

## 显示界面
- 标题：心率血氧监测
- 心率显示：红色字体，显示格式为 "XX.X bpm"
- 血氧显示：绿色字体，显示格式为 "XX.X%"
- 网络状态：显示WiFi连接状态和MQTT连接状态
- 设备ID：显示当前设备ID

## JSON数据格式
上传到MQTT的数据格式：
```json
{
  "commType": "Wifi",
  "sensorType": "Heart_SpO2",
  "data": {
    "heart_rate": "86.15",
    "spo2": "96.0"
  }
}
```

## 配置说明
- 传感器类型设置为 "01" 时启用心率血氧功能
- 数据每10秒或数据变化时上传到MQTT服务器
- 支持WiFi配网和MQTT连接

## 使用步骤
1. 将心率血氧传感器连接到串口2
2. 配置WiFi网络和MQTT服务器
3. 设置传感器类型为 "01"
4. 重启设备，系统将自动开始接收和显示数据

## 注意事项
- 确保串口2波特率设置为115200
- 数据格式必须严格按照指定格式发送
- 心率数据范围：0-300 bpm
- 血氧数据范围：0-100%
