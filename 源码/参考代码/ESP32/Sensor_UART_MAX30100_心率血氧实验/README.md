# MAX30102 心率和血氧监测项目

## 概述

基于ESP32和MAX30102传感器的心率和血氧饱和度监测系统，使用SparkFun官方MAX3010x库和算法。

## 主要特性

- ✅ 使用SparkFun官方MAX3010x库
- ✅ 集成官方心率和血氧算法
- ✅ TFT液晶屏显示
- ✅ WiFi连接和MQTT数据传输
- ✅ 实时数据采集和显示

## 硬件要求

- ESP32开发板
- MAX30102传感器模块
- TFT液晶屏
- WiFi连接

## 硬件连接

```
ESP32          MAX30102
GPIO21  -----> SDA
GPIO22  -----> SCL
3.3V    -----> VCC
GND     -----> GND
```

**注意**: 建议在SDA和SCL线上添加4.7kΩ上拉电阻。

## 软件依赖

项目使用PlatformIO管理，主要依赖：

- `sparkfun/SparkFun MAX3010x Pulse and Proximity Sensor Library@^1.1.2`
- `bblanchon/ArduinoJson@^6.21.4`
- `knolleary/PubSubClient@^2.8`

## 使用方法

### 1. 编译和上传
```bash
# 使用PlatformIO
pio run --target upload
```

### 2. 首次配置
1. 设备启动后会自动进入配网模式
2. 连接名为"IOT-4-1"开头的WiFi网络
3. 在网页界面配置WiFi和MQTT参数
4. 设置传感器类型为"01"（MAX30102）

### 3. 数据采集
1. 将手指放在MAX30102传感器上
2. 等待数据收集完成（约1-2秒）
3. 观察TFT屏幕显示的心率和血氧数据

## 技术细节

### 算法说明
- 使用SparkFun官方的心率和血氧算法
- 基于R比值法计算血氧饱和度
- 峰值检测算法计算心率
- 数据有效性验证

### 数据格式
```json
{
  "heartrate": 75.5,
  "spo2": 98.2
}
```

### 配置参数
- LED亮度: 60
- 采样平均: 4
- LED模式: 2 (SpO2模式)
- 采样率: 100Hz
- 脉冲宽度: 411μs
- ADC范围: 4096

## 故障排除

### 常见问题

1. **传感器未检测到**
   - 检查I2C连接
   - 确认电源电压为3.3V
   - 验证传感器地址（0x57）

2. **数据始终为0或无效**
   - 确保手指正确接触传感器
   - 检查LED是否亮起
   - 等待数据收集完成

3. **初始化卡顿**
   - 检查I2C通信
   - 验证传感器供电
   - 查看串口调试信息

4. **WiFi连接失败**
   - 检查WiFi配置
   - 确认网络可用
   - 重新配网

### 调试信息

- I2C设备扫描结果
- 传感器初始化状态
- 数据采集过程
- 算法计算结果
