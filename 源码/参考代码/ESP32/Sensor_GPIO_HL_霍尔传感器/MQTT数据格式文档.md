# MQTT数据格式文档

## 概述
本文档描述了火焰传感器系统的MQTT通信数据格式，包括发布主题、订阅主题以及数据格式规范。

## 系统架构
- **设备类型**: ESP32火焰传感器节点
- **通信协议**: MQTT over WiFi
- **传感器**: 火焰传感器（模拟量IO12 + 数字量IO14）

## 主题格式

### 发布主题 (Publish Topic)
```
/IOT/{deviceID}/post
```

### 订阅主题 (Subscribe Topic)
```
/IOT/{deviceID}/set
```

### 参数说明
- `{deviceID}`: 设备唯一标识符，8位字符串，通过网页配置设置

## 数据格式

### 1. 发布数据格式 (设备 → 服务器)

#### 1.1 火焰传感器数据
```json
{
  "commType": "Wifi",
  "sensorType": "FLAME",
  "data": "{\"analog\":1234,\"fire\":1}"
}
```

#### 1.2 数据字段说明
- `commType`: 通信类型，固定为 "Wifi"
- `sensorType`: 传感器类型，固定为 "FLAME"
- `data`: 传感器数据，JSON字符串格式

#### 1.3 传感器数据字段
- `analog`: 火焰传感器模拟量值 (0-4095)
  - 数值越小表示火焰越强
  - 数值越大表示火焰越弱或无火焰
- `fire`: 火焰检测状态
  - `0`: 未检测到火焰
  - `1`: 检测到火焰

### 2. 订阅数据格式 (服务器 → 设备)

#### 2.1 控制命令格式
```json
{
  "commType": "Wifi",
  "sensorType": "FLAME",
  "cmd": {
    "command": "value"
  }
}
```

#### 2.2 支持的控制命令
目前火焰传感器系统主要作为数据采集节点，暂不支持远程控制命令。

## 通信频率

### 数据发送策略
- **定时发送**: 每10秒自动发送一次传感器数据
- **状态变化发送**: 火焰状态发生变化时立即发送数据
- **发送条件**: `火焰状态变化 || (时间 % 10 == 5)`

### 状态变化检测
- 系统会记录上一次的火焰检测状态
- 当检测到火焰状态从"无火"变为"有火"或从"有火"变为"无火"时，立即发送MQTT数据
- 串口会输出"火焰状态变化，立即发送数据"的提示信息

### 连接管理
- **连接保持**: 设备会保持与MQTT服务器的长连接
- **断线重连**: 自动检测连接状态，断线时自动重连

## 数据示例

### 发布数据示例

#### 检测到火焰时
```json
{
  "commType": "Wifi",
  "sensorType": "FLAME",
  "data": "{\"analog\":856,\"fire\":1}"
}
```

#### 未检测到火焰时
```json
{
  "commType": "Wifi",
  "sensorType": "FLAME",
  "data": "{\"analog\":4095,\"fire\":0}"
}
```

### 订阅数据示例
```json
{
  "commType": "Wifi",
  "sensorType": "FLAME",
  "cmd": {
    "status": "query"
  }
}
```

## 错误处理

### 1. 连接错误
- 设备会自动重连MQTT服务器
- 重连间隔：2秒
- 最大重连次数：无限制

### 2. 数据格式错误
- 设备会忽略格式错误的订阅消息
- 发布数据格式错误会在串口输出调试信息

### 3. 传感器错误
- 模拟量读取错误：返回0
- 数字量读取错误：返回false

## 配置参数

### MQTT服务器配置
- **服务器地址**: 通过网页配置设置
- **端口**: 1883 (默认)
- **用户名**: 空
- **密码**: 空
- **客户端ID**: "home" + WiFi MAC地址

### 设备配置
- **设备ID**: 8位字符串，通过网页配置
- **传感器类型**: FLAME
- **WiFi SSID/密码**: 通过网页配置

## 调试信息

### 串口输出
设备会通过串口(115200波特率)输出以下调试信息：
- MQTT连接状态
- 传感器数据
- 数据上传状态
- 火焰状态变化提示
- 错误信息

### 示例输出
```
Flame Analog Value: 1234
Flame Detected: YES
{"analog":1234,"fire":1}
火焰状态变化，立即发送数据
Sending message to MQTT topic..
{"commType":"Wifi","sensorType":"FLAME","data":"{\"analog\":1234,\"fire\":1}"}
```

## 注意事项

1. **数据格式**: 所有JSON数据必须使用UTF-8编码
2. **数值范围**: 模拟量值范围为0-4095 (12位ADC)
3. **检测逻辑**: 数字量检测到火焰时为LOW电平
4. **网络要求**: 需要稳定的WiFi连接和MQTT服务器
5. **状态变化**: 火焰状态变化会立即触发数据发送，确保实时性
6. **防抖处理**: 系统会记录上一次状态，避免重复发送相同状态
