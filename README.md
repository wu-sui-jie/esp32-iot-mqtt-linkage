# ESP32 八模块 MQTT 联动系统

「物联网项目实践」课程大作业 · 第 1 组

八块 ESP32 通过 MQTT 服务器（`yunyismart.tech:1883`）互联，遵循本组自定的
《MQTT 通信协议规范》V2.0：「信封 + 载荷」两层 JSON 报文，三条主题
`202609_PP2/1/cmd`、`/report`、`/online`。

1. 用 VS Code 打开**某一个模块的目录**（不要打开上层目录）
2. 确认 `platformio.ini` 里的依赖已安装
3. 点状态栏的 Upload（→）按钮
4. 串口监视器波特率 `115200`

### 四条板端联动

全部在板端闭环，不经过平台，延时 1 秒以内：

| 传感器 | 执行器 | 动作 |
|---|---|---|
| 4 号 sht30 温湿度 | 2 号风扇 | 温度 ≥30℃ 或湿度 ≥80% 开风扇，回落到 28℃/75% 并持续 10 秒才关 |
| 3 号 ir_beam 对射 | 1 号舵机 | 遮挡转 0°，恢复回 90° |
| 8 号 light_sensor 光照 | 5 号 RGB | ≤50 lx 亮暖白照明，≥120 lx 熄灭 |
| 6 号 flame 火焰 | 5 号 RGB + 蜂鸣器 | 多彩循环 + 间歇报警，解除后按光照重新决定 |

5 号板同时管照明与火焰报警，优先级为 **火焰 > 平台手动命令 > 光照照明**。

### 智能语音的三层播报

| 层 | 内容 | 时机 |
|---|---|---|
| 第一层 | 事件：火焰、遮挡、设备上下线、舵机与风扇的联动动作 | 状态一变立刻播 |
| 第二层 | 阈值告警：温度过高、湿度偏高、光线过暗 | 越界时播，带冷却 |
| 第三层 | 周期汇总：「环境汇总，温度26.5度，湿度60%，光照125勒克斯，对射通畅，火焰正常」 | 每 30 秒，空闲时播 |

第三层是本次重新设计的核心：它用**快照**而不是队列，
每个数据源只留最新值，所以数据来得再快，念出来的也永远是当前值。

### 引脚对照（已按原理图逐个核对）

| 板 | 外设 | GPIO | 说明 |
|---|---|---|---|
| 舵机_1号 | 舵机信号 | 14 | 舵机必须独立 5V 供电并与 ESP32 共地 |
| 舵机_1号 | 转动指示 LED | 15 | 低电平点亮，转动期间亮 |
| 风扇_2号 | 继电器 | 14 | 经 S8050 三极管驱动 |
| 红外对射_3号 | 对射信号 | 14 | 高电平 = 遮挡，可用 `IR_ACTIVE_HIGH` 取反 |
| 温湿度_4号 | SHT30 | SDA 21 / SCL 22 | I2C，地址 0x44 |
| RGB蜂鸣器_5号 | WS2812B × 4 | 27 | 4 颗串联，数据线 |
| RGB蜂鸣器_5号 | 蜂鸣器 | 14 | 无源，3 kHz 方波，经 S8050 驱动 |
| RGB蜂鸣器_5号 | 电位器（本次不实现） | 35 | 输入专用脚 |
| 火焰_6号 | 火焰 AO | 33 | DO 接在 14 上，本版不用数字量 |
| 智能语音_7号 | 语音模块串口 | RX 16 / TX 17 | 115200，8 位数据，偶校验，1 位停止位 |
| 光照_8号 | BH1750 | SDA 21 / SCL 22 | I2C，地址 0x23 |

注意几块板用同一个 GPIO 号（比如 14）是正常的：它们是**不同的板子**，
各自插在自己的底板上，互不影响。

核对方法是把模块板原理图与底板原理图对照：模块板上的 `IOxx` 经 CN2
磁吸接口直连到底板 H2 的 `GPIOxx`，两边引脚名一一对应。

### 统一的工程结构

阶段 1 之后，八个工程的结构完全一致，命名也一致：

```
<模块目录>/src/
├── my_config.h     板号、主题、凭据、引脚、协议层开关 —— 现场只改这一个文件
├── mqtt_proto.h    协议公共层：信封构造与解析、ack / dat / evt / online 发送
├── mqtt_proto.cpp  八份副本逐字节一致，改一份要同步其余七份
├── <模块>.h        本模块的业务逻辑
├── <模块>.cpp
└── main.cpp        setup / loop 调度与命令分发
```

八块板统一使用 **256dpi/MQTT** 库。协议表 18 要求 cmd 用 QoS 1、
evt 与 ack 用 QoS 1，而 PubSubClient 的 `publish()` 只能发 QoS 0，达不到要求。
