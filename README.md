# 物联网项目实践 · 第 1 组大作业

八个 ESP32 模块通过 MQTT 互联，配合 Web 端与安卓 App，构成一个多设备联动系统。
通信遵循本组自定的《MQTT 通信协议规范_第1组》V2.0：「信封 + 载荷」两层 JSON
报文，三条主题 `202609_PP2/1/cmd`、`/report`、`/online`，服务器
`yunyismart.tech:1883`。

| 板号 | 模块 | device | 类型 | 工程目录 |
|---|---|---|---|---|
| 1 | 舵机 | `servo` | 执行器 | [`舵机_1号`](源码/ESP32嵌入式开发/舵机_1号) |

| 5 | ADC / RGB / 蜂鸣器 | `rgb` `buzzer` | 综合 | [`RGB蜂鸣器_5号`](源码/ESP32嵌入式开发/RGB蜂鸣器_5号) |

点状态栏的 Upload 按钮即可编译烧录，串口监视器 115200。

### 四条板端联动

传感器与执行器之间直接联动，不经过平台，延时在 1 秒以内：

| 传感器 | 执行器 | 动作 |
|---|---|---|
| 4 号 温湿度 | 2 号 风扇 | 温度 ≥30℃ 或湿度 ≥80% 开风扇；回落到 28℃/75% 并持续 10 秒才关 |
| 3 号 对射 | 1 号 舵机 | 遮挡转到 0°，恢复回到 90° |
| 8 号 光照 | 5 号 RGB | ≤50 lx 亮暖白照明，≥120 lx 熄灭 |
| 6 号 火焰 | 5 号 RGB + 蜂鸣器 | 多彩循环 + 间歇报警，解除后按光照重新决定 |

5 号板同时参与后两条，板内按 **火焰报警 > 平台手动命令 > 光照照明** 仲裁。

## 仓库说明

- 每个模块目录下都有 `.gitignore`，`.pio/`（PlatformIO 构建产物，共约 290 MB）、
  `.vscode/` 等不纳入版本管理，克隆后首次编译会自动重新下载依赖
- 八个工程共用同一份协议层代码（`mqtt_proto.h/.cpp`），八份副本逐字节一致，
  改一份要同步其余七份
