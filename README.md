# ESP32 八模块 MQTT 联动系统

「物联网项目实践」课程大作业 · 第 1 组

八块 ESP32 通过 MQTT 服务器（`yunyismart.tech:1883`）互联，遵循本组自定的
《MQTT 通信协议规范》V2.0：「信封 + 载荷」两层 JSON 报文，三条主题
`202609_PP2/1/cmd`、`/report`、`/online`。

**每个目录都是一个独立的 PlatformIO 工程**，可单独编译、单独烧录。

## 编译与烧录

1. 用 VS Code 打开**某一个模块的目录**（不要打开上层目录）
2. 确认 `platformio.ini` 里的依赖已安装
3. 点状态栏的 Upload（→）按钮
4. 串口监视器波特率 `115200`
